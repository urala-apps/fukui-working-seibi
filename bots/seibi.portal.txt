■ポータルサイトについて
各助成金の申請手続きをオンラインで簡単に。対象となる助成金を確認し、申請を始めましょう。
各助成金のページから、募集要項（PDF）・必要書類（Word・Excel等）をダウンロードでき、申請書・実績報告書はメールで提出します。
※申請にあたっては、事前に募集要項をご確認ください。申請書類に不備がある場合は受理できませんのでご注意ください。

・国の業務改善助成金を活用した事業者
・大幅な賃上げで従業員のモチベーションアップを図りたい事業者

No.08 「人への投資」支援事業補助金
・リスキリングで従業員の人材育成を行いたい事業者
・短時間の教育訓練を受講させたい事業者
・中産大研修やＩＴ研修をお得に受講したい事業者

■各助成金のページの「補助金の詳細」

【No.01 スポットワーカー活用支援事業補助金】
短時間・単発労働者であるスポットワーカー等を活用するにあたり、デジタル技術を用いたマッチングサービス等を利用した事業者を支援します。
本補助金は、スポットワーカー（短期・単発の働き手）を活用するために必要な環境整備や仕組みづくりに取り組む中小企業等に対し、その経費の一部を補助するものです。
対象者：過去に県から本補助金の支給を受けたことがない事業者（所）
補助対象経費：マッチングサービス利用料
補助率：1/3
補助限度額：10万円
申込受付期間：2026年4月1日〜2027年1月29日
補助対象期間：申込書記載の事業実施予定時期の始期日※〜2027年3月10日
※スポットワーカー活用前に申込確認結果通知を受けている必要があります。
申請の流れ：①要項を読む → ②申請を行う（申請書類を作成し提出） → ③事務局から申込内容確認結果の通知（審査後、事業参加の可否をメールで通知） → ④スポットワーカー活用（事業の実施） → ⑤実績報告を行う（事業完了後に実績報告書を提出） → ⑥実績報告の確認 → ⑦事務局から承認通知（交付決定・額の通知、メール・書面） → ⑧交付請求書の提出（振込先口座と請求書を返送） → ⑨補助金が振り込まれます

【No.02 外国人労働者受入環境整備事業補助金】
外国人労働者に、就業地として福井県を選択してもらうとともに、福井での就業および暮らしに対する満足度を高め、長期にわたって活躍できる環境を整備することにより、企業の人手不足の解消を図ります。
福井県内に本社を持つ企業を対象に、特定技能・技能実習などの在留資格を持つ外国人労働者の就業・生活・住宅環境を改善する取組に要した経費の1/3を補助します。
対象者：県内事業所において以下の在留資格を持つ外国人労働者を現に雇用し、今後も継続して雇用する予定である事業者、または新たに雇用する具体的な計画がある事業者
補助対象経費：県内事業所における外国人労働者の就業・生活環境の改善のための取組等に係る経費　①就業環境整備（母国語のマニュアル作成等）②生活環境整備（寮の冷暖房設置、普通自動車運転免許の取得にかかる費用等）③住宅環境整備（寮の増改築・寮用物件の取得等）
補助率：1/3
補助限度額：30万円/事業者。ただし、住宅環境整備を含む場合100万円/事業者
申請受付期間：〜2027年2月26日（必着）※ただし、予算上限額に達し次第、募集を締め切ります。
補助対象期間：交付決定日〜2027年3月31日 ※交付決定前に着手（契約、発注、納入、検収、支払等）したものは補助対象外です。
申請の流れ：①要項を読む → ②申請を行う → ③事務局から交付決定の通知（審査後、承認の可否をメールで通知） → ④補助事業の実施（※交付決定前に既に着手したものは補助対象外） → ⑤実績報告を行う → ⑥実績報告の確認 → ⑦事務局から承認通知（交付決定・額の通知） → ⑧交付請求書の提出 → ⑨補助金が振り込まれます

【No.03 副業・兼業マッチング支援事業補助金】
福井県では、初めてふくいプロフェッショナル人材総合拠点を通じて副業・兼業プロ人材をマッチングし、副業人材のスキルを活用する福井県内に事業所等を有する事業者に対して補助いたします。
はじめて副業・兼業人材を活用する県内事業者に、負担経費の一部を補助します。
対象者：ふくいプロフェッショナル人材総合戦略拠点（以下、プロ拠点）を通じて、はじめて副業・兼業人材を活用する県内事業者（プロ拠点HP：https://fukui-pro.pref.fukui.lg.jp/）
補助対象経費：マッチング手数料、副業・兼業人材に支払う報酬、旅費
補助率：対象経費の8/10
補助限度額：50万円
申請受付期間：〜2026年12月11日（予定）※ただし、予算上限額に達し次第、募集を締め切ります。
補助対象期間：交付決定日〜2027年1月31日
申請の流れ：No.02と同じ9段階（④補助事業の実施：交付決定前に既に着手（受講料の支払、研修実施など）したものは補助対象外）

【No.04 ふくい採用力強化支援事業補助金】
人材採用にかかる課題を抱えている県内中小企業に対し、企業の課題解決に資する独自の取組みを支援します。
対象者：令和8年度に「採用力強化支援企業」と認定された企業のみ（今年度の募集は終了しました）
補助対象経費：採用力の強化に資する独自の取組みにかかる経費（以下、例）ア 採用にかかる媒体の製作費等（パンフレット、チラシ、プレゼン資料等作成、採用に関するホームページ、SNS、ＰＲ動画等の制作・改修）イ 企業説明会（ウェブ活用型も含む）等の実施に係る経費（参加費、会場使用料、ブース装飾品の作製費、システム利用に係る基本契約料、管理料等）ウ オンライン採用に係る経費 エ 採用担当者等が受講する採用力強化に資する研修に要する経費 オ インターンシップ等の採用企画の設計・開催等にかかる経費
補助率：1/3
補助限度額：60万円
申請受付期間：別途連絡します（通年募集はしていません）
補助対象期間：交付決定日〜2027年3月31日
申請の流れ：No.02と同じ9段階（④交付決定前に既に着手（契約、発注、納入、検収、支払等）したものは補助対象外）

【No.05 人手不足業就職チャレンジ応援事業奨励金】
担い手不足が深刻な業種（以下、人手不足業）に対する求職者の就職意欲を高めるため、主に人手不足業以外に勤務していた方が離職後に、事業所独自のインターンシップや公的職業訓練、非正規雇用から正規雇用に転換などを経て、人手不足業の事業所に正社員として雇用され、３か月以上継続して勤務された方を対象に奨励金を支給します。
本奨励金は、人手不足業の事業所に正社員として就職し、3か月以上勤務された方に対して30万円を支給する制度です。異業種から人手不足業に正社員として就職、または人手不足業の事業所で非正規雇用から正規雇用に転換した方などが対象者となります。
対象者：建設・介護・運輸・IT・製造の事業所に就職する方で、要件を満たす方
奨励金：30万円
申請受付期間：2026年4月15日〜2027年3月12日
申請の流れ：①要項を読む → ②支給申請書兼請求書を提出（提出書類の確認を行います） → ③事務局から交付決定の通知（交付決定・額の通知、メール・書面） → ④補助金が振り込まれます
（申請は個人（就職した本人）が行います。実績報告の提出はありません）

【No.06 ふくい業務改善・賃上げ応援事業(A)補助金】
国の業務改善助成金の交付額確定通知書を受け取った中小企業事業者に対し助成します。
福井県では、最低賃金の引上げに伴い、国の「業務改善助成金」を活用する事業者に対し、その支給決定額の5分の1（20%）を県独自に上乗せして補助しています。
対象者：国の「業務改善助成金」の交付決定を受けた事業者 ※福井労働局へ業務改善助成金の交付申請を行い、令和8年4月1日から令和9年2月26日までの期間に交付決定通知を受けている事業者
補助率：国の「業務改善助成金」支給決定額の1/5
申請受付期間：令和8年9月1日〜令和9年2月26日
（ページにあるのは「募集要項」「必要書類」「申請書提出（メール）」の3つ。実績報告の提出はありません）

【No.07 ふくい業務改善・賃上げ応援事業(B)奨励金】
国の「業務改善助成金」の交付決定通知を受け取り、事業場内最低賃金を一定以上引き上げる事業者に奨励金を支給します。
事業場内の最低賃金を一定以上引き上げる事業者に対し、賃上げの原資となる奨励金を支給し、賃上げを行いやすい環境整備を支援します。
対象者：国の業務改善助成金の交付決定通知書を受け取った事業者※で、福井県内の事業場において、事業場内最低賃金を90円以上引き上げた者 ※国の業務改善助成金について、福井労働局に交付申請を行い、令和8年4月1日から令和9年2月26日までの期間に交付決定通知を受けている事業者であること
支給額：10万円×引き上げる労働者数（1事業者あたり最大10人）
申込受付期間：令和8年9月1日〜令和9年2月26日
※申請にあたっては、事前に支給要綱をご確認ください。
（ページにあるのは「募集要項」「必要書類」「申請書提出（メール）」の3つ）

【No.08 「人への投資」支援事業補助金】
生産性の向上や事業の拡大等を目的として、従業員に向けた短期間の教育訓練を実施する際にかかる企業負担を補助し、県内中小企業における人材育成の取組を促進します。
本補助金は、概ね10時間未満の教育訓練を従業員に受講させた中小企業等に対し、教育訓練にかかった受講料や訓練時間分の賃金などの経費の一部を補助するものです。遠方で開催される研修に参加される場合は、一定の条件のもと、旅費や交通費等についても補助対象となります。
対象者：県内に本社機能を有する中小企業者等
補助対象経費：①社外の教育研修機関等で受ける研修等 ②自社独自の社内研修等のうち研修時間が10時間未満のもの
補助率：1/2 ※要件を満たす場合、2/3
補助限度額：上限15万円/社 ※上乗せ等要件あり
申請受付期間：2026年4月1日〜2027年2月26日 ※予算上限に達し次第終了します。
補助対象期間：交付決定日〜2027年3月31日
申請の流れ：No.02と同じ9段階（④補助事業の実施：交付決定前に既に着手（受講料の支払、訓練実施など）したものは補助対象外）
